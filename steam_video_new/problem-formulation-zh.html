固定流式语义记忆中的支持渐进式导航

Support-Progressive Semantic Navigation over Fixed Latent History for Streaming Video QA

Problem formulation · 2026-07-17 · English

核心问题

Question 如何在不可检索的连续历史状态中逐步找到答案？

流式 Video-LLM 必须在固定预算下压缩 video 与 caption 历史。我们不保留 frames、segments、nodes 或 graph；历史只存在于单一固定的 LLM-aligned embedding state 中。问题到来后，系统无法检索一条显式 evidence chain，只能在连续状态中逐步变换问题表示。

How can a streaming Video-LLM navigate a fixed, query-independent multimodal semantic state to progressively acquire answer-supporting information, without retrieving discrete memory items?

主贡献不是 memory architecture，而是 navigation：每一步选择一个 semantic operation，从同一连续状态读取互补信息，并提高正确答案相对 plausible alternatives 的 support margin。

1. Problem setting：固定、查询无关的多模态语义状态

Z_t = Fuse(E_V(V_t),E_C(C_t)) M_t = U_φ(M_{t-1},Z_t), M_t∈R^{N×d}, N=constant

M_t 在任何未来问题出现前在线写入，并联合编码 entities、events、states、temporal relations、caption/ASR semantics、visual-only details 与 cross-modal conflicts。

历史表示严格不包含：

  • 独立 evidence items、frames、clips 或 caption entries；
  • timestamps、pointers、provenance、nodes 或 edges；
  • 增长的 memory bank、Top-K retrieval 或 raw-video replay。

因此本文研究的是 answer-supporting latent information，不能声称返回 grounded 或 source-traceable evidence。

2. Streaming interface：当前感知与历史状态解耦

Current path: W_t = RecentWindow(Z_{t-w:t}) History path: M_t = U_φ(M_{t-1},Z_{t-w-1})

W_t 保留最近几秒的 raw/轻压缩 tokens，保护 object、attribute、action、OCR 与细节感知；M_t 只表示更早历史。该分离是 streaming interface，不是 novelty。

3. 主方法：Semantic-State Navigator

初始化 query state，并在固定历史状态上执行最多 K 步 operation-conditioned read：

u_0=E_Q(q) π_k=p_ψ(o_k|u_{k-1},q) e_k=Σ_o π_{k,o}e_o^{op} r_k=CrossAttn(u_{k-1}+e_k,M_t) u_k=GRU(u_{k-1},r_k,e_k)

第一版只使用一个共享 reader 和六个轻量 operation embeddings：

O={GROUND_ENTITY, RESOLVE_EVENT, TRACE_STATE, LINK_TEMPORAL, CHECK_CONFLICT, COMPOSE}

Operation 不对应独立 agent 或网络专家；它只是控制同一 reader 在每一步需要从 latent state 解码哪类语义关系。

4. Navigation 的训练信号：support progress，而非 attention 次数

第 k 步后的 answer-support margin：

m_k=s(a^+|u_k,W_t)−max_{a^-∈A^-}s(a^-|u_k,W_t)

要求 navigation 每一步提高正确答案相对最危险 plausible alternative 的区分：

L_progress=Σ_k max(0,m_{k-1}+δ−m_k)

防止连续 steps 重复读取同一 latent direction：

L_comp=Σ_{k>1} Overlap(α_k,α_{k-1})

最终导航目标：

L_nav=L_QA+λ_pL_progress+λ_cL_comp+λ_oL_operation

L_operation 可由 question semantics / teacher trace 提供弱监督，但不能成为硬编码程序。若打乱 operation 不影响结果，则 semantic navigation claim 失败。

5. 与 SelectStream 的核心替换：graph routing → semantic navigation

SelectStream 导航“证据存在哪里”；本文导航“需要对连续语义状态执行什么变换，才能逐步形成答案”。

6. Answerability collapse：navigation 要恢复的 failure

coarse semantic relevance survives ≠ future claim remains answerable

固定压缩可能记住红包、A、B 与窗边，却丢失 handoff、pickup 或 object continuity。Navigator 的目标不是重建原始 evidence，而是恢复区分正确答案与 plausible alternative 所需的 latent semantics。

FullHistoryAnswerable(q,S_≤t)=1 LatentMemoryAnswerable(q,M_t)=0

7. 外层约束：历史导航不能破坏当前感知

主 novelty 是 navigation；perception–memory trade-off 是 streaming 约束。Full-history teacher 与 recent-only teacher 分别定义历史收益和当前保护：

L_hist=KL[p_T(a|q,W_t,H_t)||p_S(a|q,W_t,M_t)] L_current=KL[p_R(a|q,W_t)||p_S(a|q,W_t,M_t)]
min L_hist+L_nav s.t. E_{q∈Q_current}L_current≤ε, |M_t|=N

方法必须提高 historical questions，同时将 current interference 控制在预设 ε 内。

Go / No-Go

14. 论文成立门槛

Go：等 FLOP 下 semantic navigator 显著优于 deeper one-shot、普通 recurrent attention 与 latent deliberation；operations 对问题类型有稳定对应，打乱会降点；support margin 随 step 提升；并在 historical questions 上接近或超过 SelectStream，同时保持 current perception。

No-Go：收益由 Qwen embeddings 或更多 depth 解释；operations 可任意打乱；progress loss 等价于普通 deep supervision；或 fixed state 无法接近 SelectStream 的 graph retrieval。此时方法只是旧 recurrent attention 加现代 backbone。

一句话定位

We introduce support-progressive semantic navigation over a fixed, query-independent, LLM-aligned multimodal history state, progressively transforming the question without retrieving discrete video evidence.

备选路线

15. Causality-aware latent memory（贴近 SelectStream）

统一 framing：节点保存局部视觉证据；带不确定性的 latent relation 表示解释依赖；consolidation 保护推理路径；query 随已读证据与当前因果假设演化。

How can a bounded latent memory preserve temporal and explanatory reasoning paths under continual consolidation, while supporting closed-loop query-dependent navigation?

表述要克制：latent explanatory dependency / causal-support graph——不要声称从 observational streaming video 学到真实因果图。

15.1 节点记忆 + latent causality

m_i=(h_i,τ_i,p_i) c_ij=(r_ij,u_ij,d_ij)=f_causal(h_i,h_j,Δτ_ij,…) G=(M,C)

r：关系嵌入；u：不确定性；d：方向。不要做全量 O(N²) 两两因果推断。在线：cheap Top-K 候选（recency / entity / semantic / state / causal frontier）→ 只对 P_j 做 relation inference → O(NK)，K≪N。长程依赖靠 causal landmarks + hierarchical summaries，而不是扫全部节点。

15.2 Consolidation：不是“按因果性最低删除”

因果效用有用，但孤立/未决/事实节点仍可能有价值；关系模型会错；很多 QA 只需视觉事实而非因果链。多目标重要性 + 三种操作：

I_i=λ_s I_i^sem+λ_t I_i^temp+λ_c I_i^causal+λ_q I_i^query+λ_u I_i^unc ops ∈ {keep, merge, abstract, delete}
  • Delete — 冗余、因果贡献低、不确定性低、非唯一观察。
  • Merge — 同状态持续；保留时间跨度。
  • Abstract — 把因果 motif 压成带 provenance 的 summary node（最强新操作）。

保护 bridge、唯一状态转移、高影响 cause、未解决 hypothesis。三点中最强 novelty：reasoning-preserving consolidation。

15.3 Query 随时间：不要拼成一个 embedding

z_t=[z_t^q; z_t^e; z_t^c; z_t^r] z_t^c=PathEncoder(current evidence path) a_t∈{retrieve-sem, follow-cause/effect, find-bridge, seek-counter, backtrack, stop}

拆分：问题 / 已收集证据 / 当前因果路径假设 / 缺失需求。轨迹：match → anchor effect → search cause → complete bridge → verify / counter。下一跳依赖真实 retrieval outcome（闭环），而非一次性 symbolic program。

15.4 贡献排序与相关工作

  1. 固定预算下的 causality-aware consolidation（主贡献）。
  2. Causal-path-conditioned closed-loop navigation。
  3. 可修订、带不确定性的 latent relation memory（支撑前两者）。

15.5 为何需要 world model：延迟收益与不可逆性

只放在本 causality-aware track：continuous-state 路线没有离散 evidence actions / retrieval transitions，硬套 world-model framing 不自然。这里是短视的 belief-transition / reasoning-utility model，不是像素级视频 world model。

两个最强动机：

  • Bridge evidence 的延迟收益。某次检索当下可能几乎不提高 relevance / answer gain，却能打开下一跳 temporal 或 causal hop。这与 greedy iterative retrieval 形成清晰区分。例：e1 回到房间 → e2 摸空口袋（bridge）→ e3 钥匙留在房间。
  • Bounded memory 下的不可逆性。差的导航浪费检索预算；错误的 merge/delete 可能永久打断推理路径。同一 utility model 因此可同时指导 navigation 与 consolidation。

论文级表述：Existing iterative retrieval is reactive and optimizes locally useful evidence. We learn a short-horizon belief-transition model that predicts the delayed reasoning utility of semantic, temporal, and causal navigation actions, while estimating the path loss caused by memory consolidation.

Greedy retrieval: a_t = arg max_a V(s_{t+1}) Our planning: a_t = arg max_a E[V(s_{t+K})∣s_t,a]

K 保持很小（通常 1–2 步想象中的 retrieval），模型轻量、claim 可辩护。

learn T_φ(b_{t+1}∣b_t,a_t), b_t=P(relevant path∣q,E_{1:t}) r_t=Δchain completeness+Δanswerability−cost

15.6 面向视频图导航的 Implicit World State

在方法层面，将 multi-hop reasoning 建模为抽象 latent state space 中的 action-conditioned dynamics。Latent state 不要求解码成固定 belief schema、evidence list 或类似网页的显式状态：

z_t=Enc_θ(q,h_t) p_φ(ẑ_{t+1},ô_{t+1}|z_t,a_t) z_{t+1}=U_ψ(z_t,a_t,o_{t+1})

第一个 transition 是执行动作前的 prior：预测 reasoning action 可能如何改变轨迹，以及可能得到哪类 evidence。真实 retrieval/navigation action 返回 observation o_{t+1} 后，updater 再形成 posterior reasoning state。这样可以避免把 imagined evidence 当成已经观察到的事实。

在 video-graph 实例中，latent state 由以下信息条件化，但不要求把它们表示成显式 slots：

  • Ot — 当前观察：当前/最近视频事件、可见实体、动作与状态变化；
  • E1:t — 推理历史：截至当前已获得的 grounded evidence，以及获取这些证据的动作；
  • Ht — 活跃假设：候选 reasoning chains 与相互竞争的答案解释；
  • gt — 下一推理需求：当前缺失的 entity、temporal link、explanatory bridge、counterevidence 或 verification step；
  • Bt — budget：剩余 retrieval calls、latency 与 memory/navigation cost。

Navigator 不维护单一路径或固定大小的 beam，而是维护 reasoning hypotheses 与 graph locations 上的概率分布：

b_t(H,v)=P(H_t=H,v_t=v | q,E_{1:t}) π_t(a,v'|H,v)=P(a_t=a,v_{t+1}=v' | z_t,H,v) b_{t+1}(H',v')=Σ_{H,v,a} b_t(H,v)π_t(a,v'|H,v)T_φ(H'|H,v,a,v')

每一跳把 probability mass 并行分配给 semantic neighbors、temporal forward/backward nodes、explanatory predecessors/effects、bridges 与 counterevidence。兼容 successors 通过概率累加合并；contradiction 会降低或分裂 probability mass；不同 chains 按 posterior support 持续存在。计算上可以采用 entmax 等 sparse soft routing，或按 cumulative probability 自适应截断，仅忽略可忽略的小概率质量；方法本身不固定 chain 数量或每步 expansion 数量。

World model 预测的是下一步 multi-hop reasoning state，而不是评测指标。一次 transition 可以完成 entity grounding、建立 temporal order、延伸 explanatory link、暴露缺失 bridge、发现 contradiction、验证整条 chain，或使当前状态达到可以回答的条件。下面的 reasoning-stage variable 只是可解释 probe 或 auxiliary head，不是 z_t 的定义：

ρ_t∈{GROUND, TEMPORAL_LINK, EXPLANATORY_LINK, FIND_BRIDGE, SEEK_COUNTER, VERIFY_CHAIN, ANSWER, ABSTAIN}

短程 imagined rollout 比较不同并行 expansion sets 及其 successor beams：它们能否补齐所需 reasoning roles、解决 missing links、在 uncertainty 尚存时保留真正不同的 hypotheses，并以较低成本到达 verified answer state。因果/解释连贯性、uncertainty calibration、temporal correctness 与 semantic relevance 是验证这些 reasoning transitions 的四个维度，而不是显式 world-state slots。 Recall、relation F1、calibration 与 answer accuracy 同样只用于评测。

15.7 与 Reasoning World Model 和 Latent Retrieval 的边界

已有多条研究线覆盖了这一表述的重要组成部分，因此本文不能把“用 world model 做 reasoning”或“latent state transition”本身作为贡献。

  • RAP 将 LLM 同时作为 world model，并用 MCTS 在显式 reasoning states 上规划。它已经确立 reasoning-as-world-model planning，但 transition 主要发生在语言推理或环境状态中，而不是外部视频证据上的 implicit belief。
  • Coconut 将连续 hidden state 重新输入模型，并可保留多个潜在下一推理方向。它已经覆盖 latent multi-path reasoning，但不以 action-conditioned 外部证据获取或 video graph 上 observation-driven update 为核心。
  • CTRLS 明确把 CoT 建模为具有概率式 latent state transitions 与 epistemic uncertainty 的 MDP。因此它是 latent transition dynamics 的直接先例；本文的区别必须来自 evidence-grounded video navigation，而不是 latent-MDP 形式本身。
  • Agent Learning via Early Experience 让同一个 language-agent policy 根据 state–action pair 预测文本形式的下一环境状态，并把 expert、当前 policy 与其他候选动作的真实后果作为辅助监督，再进行 expert fine-tuning。其 implicit world model 被内化进 policy 参数，测试时不会单独展开 world-model rollout。本文则预测 evidence-conditioned latent reasoning belief 的 transition，并在推理时显式比较概率式导航未来。
  • Stop-RAG 学习 iterative retrieval 是否应继续的 forward-looking value。其主要控制是 stop/continue，而不是预测 semantic、temporal、explanatory、bridge 或 counterevidence expansion 将如何改变下一 reasoning state。
  • LAnR 使用 latent query 检索，并训练是否需要更多 evidence 的控制头。它更接近 latent retrieval control，而不是对 future evidence observation 与并行 reasoning hypotheses 建模的 predictive transition model。

可辩护定位：学习一个用于 streaming video-graph QA 的 evidence-conditioned implicit belief-transition model，预测概率式并行 semantic、temporal 与 explanatory navigation 在获取真实新证据后，将如何改变下一步 multi-hop reasoning state。实验必须比较 RAP-style explicit planning、latent reasoning、direct action ranking、adaptive stopping 与普通 iterative retrieval。

更高层 framing：implicit world modeling for abstract reasoning dynamics。把 multi-hop reasoning 表述为 latent state space 中的 action-conditioned transitions，由 world model 预测中间 reasoning actions 如何重塑通向答案的轨迹。该表述是 motivation 与方法抽象；论文级 novelty 仍必须通过 evidence-conditioned video navigation、observation-grounded posterior update、delayed bridge utility 与 test-time planning 来成立。

从 Early Experience 借用的训练方式：在每个真实 video-graph reasoning checkpoint 上，分别执行 expert、当前 policy 与其他 admissible navigation actions，并记录 (z_t,a_t,e_{t+1},z_{t+1})。Transition model 同时预测 evidence observation 与更新后的 latent reasoning state，也学习错误或局部看似合理动作的后果。该 one-step supervision 只用于初始化 dynamics，不能单独支撑论文 claim。决定性结果必须证明：测试时利用 learned transition model 做 rollout，能选择具有 delayed utility 的 bridge evidence，并优于“接受相同 next-state prediction 训练、但部署时不做 planning”的同一 policy。

15.8 多链搜索 → 用校准置信度回答

World model 负责生成、扩展和比较多条 reasoning chains；答案不由单条路径决定，而由多条链对候选答案的累积支持与校准置信度决定。

The world model performs test-time search over multiple temporal-causal reasoning chains, while a calibrated verifier aggregates chain-level evidence into answer confidence and controls whether to continue, answer, or abstain.

分工：world model 预测并行 node expansions 与 reasoning hypotheses 的 transition probabilities；verifier 更新并校准它们的 posterior mass；answer confidence 决定何时输出。

假设集。锚定后维护 H_t={H_t^1,…,H_t^B}，beam B≈3–8：

H^k=(e_1,r_{12},e_2,…,e_n) r ∈ {semantic, temporal, state-transition, explanatory/candidate-causal}

例：“为何回厨房？”：H_1 留下杯子→发现缺失→返回；H_2 听到声响→返回；H_3 找人说话→返回。底层可用 soft edges；推理层保持稀疏、可审计的 hypotheses。

三层置信度（不可混为一个分数）：

  1. Edge：c_{ij}^r=P(r_{ij}∣e_i,e_j)。
  2. Chain：C(H)=Verifier(q,H)——evidence / temporal / causal-explanatory / grounding，减去 contradiction 与 missing-link（不要把 edge 概率相乘）。
  3. Answer：对候选 y，聚合支持链并做 redundancy correction：
S(y)=log Σ_{H∈H(y)} exp(C(H)) P(y∣q,E)=softmax_y S(y)

最终置信度来自 evidence chains，而非 VLM token probability。

何时回答——同时满足：P(y_max)>τ_ans、与第二名的 margin、必要 roles 已覆盖、无未解决强反证。否则：

d_t ∈ {continue, verify, answer, abstain} (H^*,a^*)=arg max_{H,a} E[ΔC_answer+ΔC_chain−λcost∣H,a]

动作：temporal 前/后、causal predecessor/effect、bridge、counter-evidence、验证边。Bridge 步可能不立刻抬高答案置信度，但提升链可扩展性——即 §15.5 的延迟收益。

流水线：流式视频 → 有界 latent temporal-causal memory → 多假设初始化 → world-model rollout → 取真实证据 → 更新 edge/chain 置信度 → 比较支持与反证 → answer / continue / abstain。

MoReVQA / agentic VideoQA测试时多阶段程序 / 工具无对 latent memory 的预测式 world，无多链 belief
KGQA / Plan*RAG结构化 memory 上的多跳路径 / planning离散静态图或文本库，非持续 consolidation 的 latent 视频关系

定位：把 Embodied QA 式的 goal-directed information acquisition 迁到有界 latent video memory；world-model 的动作定义为 semantic、temporal 与 explanatory navigation。

15.9 三天视频图 + World Model 导航冲刺

三天内先在 20–50 个短视频上构建小型 temporal-explanatory event graph，再验证一至两步 world-model lookahead 能否改善图上导航。边表示从观察视频、caption、subtitle 与事件顺序推断出的 candidate causal-support relation，不能声称识别真实因果。可复用 Video Skills 的解码、分段、caption 与评测基础设施，但两篇论文的方法和运行时保持独立。

  1. Day 1 — 视频事件图：将视频切分为 events，提取 entities、actions、state changes 与 timestamps；构建 temporal-next、same-entity、state-transition、explanatory-support 和 contradiction 等稀疏候选边。先用廉价 retrieval 提议 Top-K neighbors，再由 VLM/teacher 标注 relation type、direction、uncertainty 与简短 warrant，并人工抽查部分边。
  2. Day 2 — World Model navigator：定义 {retrieve-semantic, follow-temporal, follow-explanatory, find-bridge, seek-counter, stop} 动作。从 question-conditioned checkpoints 出发，训练或校准轻量 transition model 做一至两步导航。维护 chains 与 graph nodes 上的 posterior mass，并行路由到多个 successors，通过概率累加合并兼容状态，只为计算效率采用自适应 probability-mass truncation。
  3. Day 3 — 等预算评估：比较 semantic Top-K、greedy one-step、无 transition 的 direct action ranker、无 learned world model 的 beam search、oracle graph path 与 world-model navigation。评估 answer accuracy、supporting-event Recall@K、bridge retrieval、chain completeness、relation precision、latency 和 oracle regret，并通过打乱 edges 与 transition targets 做因果控制。

Go：人工抽查的 candidate-edge precision 至少 70%；至少 20% 的有效问题需要 bridge event 或 delayed-utility hop；在相同 retrieval calls 下，world model 相比 greedy 与 direct-ranking baselines 的 supporting-event Recall@K 至少提高 10 个百分点，或 answer accuracy 至少提高 5 个百分点；打乱 edge/transition 后收益必须明显下降。No-Go：图噪声过高，大部分问题由直接 semantic retrieval 解决，非预测式 beam/direct ranker 能追平 world model，或等预算后收益消失。

15.10 统一 World Model、Factor Graph 与 Causal Reasoning

本节给出组织 §15.5–§15.9 的更高层研究 framing。它不替代 evidence-conditioned video-graph navigation 的论文级 claim，而是澄清我们所说的 world model、图结构与因果分别指什么。

15.10.1 最初问题：能否为抽象问题求解建立世界模型？

传统世界模型主要学习物理或游戏环境中的状态转移：

s_{t+1}=F(s_t,a_t)

更抽象的问题是：能否把多跳推理、证据获取和问题求解表示成一个动态系统，并学习其状态如何随推理动作和新证据演化？

z_{t+1}=F_θ(z_t,a_t,o_{t+1})
  • z_t：当前问题求解 / belief state；
  • a_t：推理、检索、验证、回溯等动作；
  • o_{t+1}：动作后获得的新证据；
  • z_{t+1}：更新后的问题求解状态。

已有工作分别涉及语言空间规划、latent reasoning、iterative retrieval 与 agent world modeling，但很少真正学习：reasoning action 如何改变证据状态、假设、不确定性与未来可解性。直接建模“通用抽象问题求解状态”过于宽泛；最大困难不是 architecture，而是无法明确回答：状态变量是什么、推理动作是什么、状态转移监督来自哪里、不同合理路径的下一状态如何统一、以及如何验证 latent state 是否真正表示问题求解状态。因此更现实的起点是具有清晰实体、事件、时间与证据结构的 multi-hop video reasoning。

15.10.2 为什么不只使用普通 reasoning graph？

普通 GraphRAG、knowledge graph 或 graph-of-thought 通常用 semantic similarity、entity overlap、temporal adjacency 或 retrieval relationship 连接文档、实体、事件、thoughts 或 retrieved evidence。它们回答“哪些信息彼此相关？”我们希望表示的是：当前有哪些未知变量、已有证据对这些变量施加了什么约束、哪些假设仍然不确定、以及加入新证据后整个 belief 应如何更新。因此核心不只是“在图上导航”，而是在结构化变量和约束上持续进行推断。

15.10.3 Factor graph 的作用

因子图将全局联合分布分解成一组局部约束：

p(X∣E) ∝ ∏_i φ_i(X_i,E_i)

Variable nodes 表示未知变量；factor nodes 表示 evidence、约束、依赖或状态转移。新证据加入后可重新计算全局 posterior，后期证据可反向修正早期假设。在 multi-hop video reasoning 中，变量可包括 entity identity、event occurrence、object state、temporal location、causal relation、bridge entity、intermediate subanswer 与 final answer。Factors 可包括：

  • φ_visual — 某视频片段是否支持某个事件或状态；
  • φ_identity — 不同片段中的人物/物体是否为同一实体；
  • φ_temporal — before / after / during；
  • φ_causal — 一个事件是否 causes 或 enables 另一个事件；
  • φ_consistency — 不同证据或假设是否一致；
  • φ_answer — 中间变量与最终答案是否兼容。

因此多跳推理可理解为：不断获取新的 evidence factors，并对隐藏变量进行增量推断。

15.10.4 Reasoning 与 evidence 应联合建模

不能只说“用因子图建模 reasoning”。更准确的是：用因子图联合建模 reasoning、evidence acquisition 与 belief update：

G_t →[reasoning] a_t →[evidence acquisition] e_{t+1} →[factor construction] φ_{t+1} →[global inference] G_{t+1}

Reasoning 决定：当前哪个变量最需要解析、应查看哪个时间段、应追踪哪个实体、应验证哪条时间/因果关系、应补全哪个 reasoning gap、以及是否回溯或停止。新 evidence 不是简单追加到 memory，而是转化成新的 factor，并改变整张图上的 belief。更合适的描述是：

  • Reasoning as active constraint acquisition；
  • Joint evidence acquisition and reasoning over a dynamic epistemic factor graph。

15.10.5 Factor graph 与 world model 如何结合？

Factor graph 可作为 world model 的结构化状态表示。普通 latent world model 学习 z_{t+1}=F_θ(z_t,a_t)；结构化版本则学习：

G_{t+1}=F_θ(G_t,a_t,o_{t+1})

G_t 表示当前对世界和问题的 posterior：哪些实体/事件已确定、哪些关系仍未知、哪些 evidence 支持或反驳某假设、当前答案分布如何、下一步应获取什么约束。World model 可包含两类 transition：

  • 世界状态转移 φ_world(X_t,u_t,X_{t+1}) — 例如 person presses switch → light turns on；
  • 认识状态转移 φ_belief(B_t,a_t,e_{t+1},B_{t+1}) — 例如 inspect earlier clip → resolve entity identity → reduce answer uncertainty。

因此 world model 不只预测视频未来，也预测获取某项证据后问题求解图如何变化——与 §15.5–§15.6 的 belief-transition model 一致。

15.10.6 Factor graph 的 SLAM 类比

Frank Dellaert 的 factor graph / GTSAM 思路提供强启发，但不等于我们要实现完整 GTSAM：

SLAMReasoning + Evidence
Robot pose当前 observation / reasoning location
Landmark实体、事件、未知事实或子目标
Measurement factorVideo evidence factor
Odometry factorTemporal 或 reasoning transition factor
Loop closure新证据重新约束早期假设
Smoothing利用后期证据修正早期 belief
Active SLAM主动选择下一项最有价值的 evidence

关键价值是 incremental smoothing。传统 autoregressive reasoning A→B→C→D 若 B 错了往往沿错误轨迹继续；因子图允许后期证据触发全局 posterior update，并修正早期变量——相当于 reasoning 中的 loop closure。

15.10.7 Factor graph 与因果性的关系

因子图本身不等于因果图。普通 factor φ(X,Y) 只表达局部兼容性或概率依赖，无法自动说明 X→Y 还是 Y→X。因子图最擅长 evidence fusion、uncertainty、局部约束分解、全局一致性与 posterior correction。因果语义必须通过变量定义与特定 causal / temporal / transition factors 额外引入。系统可同时包含非因果 identity factors、temporal factors、evidence-support factors、consistency factors、causal mechanism factors 与 action-conditioned transition factors。更准确的表述是：

Epistemic factor graph with causal-temporal and transition factors

——而不是把所有图边都称为 causal。

15.10.8 因果、因果推断与因果推理

  • 因果 — 世界中的生成机制，例如 Y=f(X,U) 或 press switch → light on。
  • 因果推断 — 从 observational / interventional data 中识别和估计因果结构或效应，例如 P(Y∣do(X=x))。
  • 因果推理 — 在已有或学习到的因果模型上进行预测、干预与反事实推演。

当前设想的目标不主要是经典统计学意义上的 causal effect estimation，而是下面两阶段：从视频证据恢复可用的因果—时序结构，再将该结构作为 world-model state 进行推理与导航。

15.10.9 两阶段框架

第一阶段：建立 causal-temporal evidence graph。 从流式视频和问题中增量建立 G_t=(V_t,E_t)：节点包括 entities、events、states、evidence、hypotheses 与 unresolved variables；边/factors 包括 precedes、during、same entity、supports、contradicts、causes、enables 与 state transition。目标：E_{1:t},Q → G_t。

第二阶段：将图作为 world-model state。 学习 G_{t+1}∼T_θ(G_t,a_t)（并按 §15.6 用真实 observation 更新），再进行 causal reasoning、multi-hop graph completion、evidence navigation、hypothetical rollout、answer prediction 与 failure recovery。动作可包括：inspect a temporal window、track an entity、verify an event、follow a causal predecessor、search for a consequence、test a hypothesis、acquire a missing factor。

Causal-temporal graph induction → Factor-graph inference → Graph world modeling → Multi-hop reasoning and evidence acquisition

15.10.10 为什么先从 multi-hop video reasoning 开始？

视频提供相对清晰的结构：时间可观测、实体可追踪、事件可定位、状态变化可抽取、evidence 可对应具体 clip，且多跳问题通常包含明确的 temporal/entity/event chain。例如：“拿走杯子的人，在进入房间之前做了什么？”需要定位拿杯事件、识别执行者、在更早视频中追踪同一实体、定位进入房间、找到前序动作，并检查 identity 与 temporal consistency——可自然表示为 identity / event / temporal 约束链。文本多跳 QA（如 MuSiQue / 2Wiki）仍可用作 belief transition 与 delayed bridge utility 的 mechanism sandbox，但论文 novelty 仍须由视频证据设定支撑（§15.7）。

15.10.11 技术上最现实的第一版

第一版不应声称建立通用 reasoning world model，也不需要立即实现完整 GTSAM 式系统。可先构建：(1) 动态 evidence factor graph；(2) 少量定义明确的变量；(3) learned visual、identity、temporal 与 causal factors；(4) 图消息传递或近似 posterior inference；(5) 主动选择下一段视频 evidence 的 controller；(6) 新证据加入后的全局 belief revision。最关键的实验问题包括：

  • 图式全局更新是否比 append-only memory 更能修正早期错误？
  • active factor acquisition 是否比 top-k retrieval 更节省观察预算？
  • factor graph 是否在跨时间、跨事件、桥接实体问题上更有效？
  • causal-temporal factors 是否改善多跳 chain consistency？
  • 后期 evidence 是否能够修正早期错误的 entity/event binding？

15.10.12 最终研究定位

不宜直接声称：“General causal world model for abstract reasoning.” 更稳妥、具体的定位是：

  • A dynamic causal-temporal factor graph for joint evidence acquisition and multi-hop video reasoning.
  • A structured graph world model that incrementally integrates video evidence, revises latent event hypotheses, and actively navigates causal-temporal reasoning chains.

更高层的长期愿景：将问题求解表示为在动态 epistemic factor graph 上进行主动约束获取、全局 belief update 与 action-conditioned world-model planning。
