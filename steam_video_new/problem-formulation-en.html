Support-Progressive Navigation over Fixed Streaming Semantic Memory

Semantic-state navigation without discrete evidence retrieval for streaming Video QA

Problem formulation · 2026-07-12 · 中文

Core problem

How can a question progressively find an answer inside a non-retrievable continuous history state?

A streaming Video-LLM must compress video-caption history under a fixed budget. We retain no frames, segments, nodes, or graph: history exists only in one fixed, LLM-aligned embedding state. Once a question arrives, the system cannot retrieve an explicit evidence chain; it must progressively transform the question representation within the continuous state.

How can a streaming Video-LLM navigate a fixed, query-independent multimodal semantic state to progressively acquire answer-supporting information, without retrieving discrete memory items?

The main contribution is navigation, not memory architecture: each step selects a semantic operation, reads complementary information from the same continuous state, and increases support for the correct answer over plausible alternatives.

1. Problem setting: fixed query-independent multimodal semantic state

Z_t = Fuse(E_V(V_t),E_C(C_t)) M_t = U_φ(M_{t-1},Z_t), M_t∈R^{N×d}, N=constant

M_t is written online before any future question and jointly encodes entities, events, states, temporal relations, caption/ASR semantics, visual-only details, and cross-modal conflicts.

History contains no independent evidence items, frames, clips, caption entries, timestamps, pointers, provenance, nodes, edges, growing bank, Top-K retrieval, or raw-video replay.

The claim is about answer-supporting latent information, not grounded or source-traceable evidence.

2. Streaming interface: decouple current perception and history

Current path: W_t = RecentWindow(Z_{t-w:t}) History path: M_t = U_φ(M_{t-1},Z_{t-w-1})

W_t retains raw/lightly compressed recent tokens for object, attribute, action, OCR, and fine detail. M_t represents only older history. This split is a streaming interface, not the novelty.

3. Main method: Semantic-State Navigator

Initialize the query state and perform at most K operation-conditioned reads over fixed history:

u_0=E_Q(q) π_k=p_ψ(o_k|u_{k-1},q) e_k=Σ_o π_{k,o}e_o^{op} r_k=CrossAttn(u_{k-1}+e_k,M_t) u_k=GRU(u_{k-1},r_k,e_k)

The first version uses one shared reader and six lightweight operation embeddings:

O={GROUND_ENTITY, RESOLVE_EVENT, TRACE_STATE, LINK_TEMPORAL, CHECK_CONFLICT, COMPOSE}

Operations are not agents or expert networks. They condition what semantic relation the shared reader should decode at each step.

4. Navigation supervision: support progress, not attention depth

m_k=s(a^+|u_k,W_t)−max_{a^-∈A^-}s(a^-|u_k,W_t)

Each step should improve discrimination between the correct answer and the strongest plausible alternative:

L_progress=Σ_k max(0,m_{k-1}+δ−m_k)

Complementarity discourages repeated reads of the same latent direction:

L_comp=Σ_{k>1}Overlap(α_k,α_{k-1})
L_nav=L_QA+λ_pL_progress+λ_cL_comp+λ_oL_operation

L_operation may use weak supervision from question semantics or teacher traces but must not become a hard-coded program. If operation shuffling has no effect, the semantic-navigation claim fails.

SelectStream navigates where evidence is stored; this work navigates which semantic transformation is required to decode an answer from a continuous state.

6. Answerability collapse: the failure navigation addresses

coarse semantic relevance survives ≠ future claim remains answerable

Compression may preserve a bag, A, B, and a window while losing handoff, pickup, or object continuity. The navigator does not reconstruct raw evidence; it recovers latent semantics needed to discriminate the correct answer from plausible alternatives.

FullHistoryAnswerable(q,S_≤t)=1 LatentMemoryAnswerable(q,M_t)=0

7. Outer constraint: history navigation must not corrupt current perception

L_hist=KL[p_T(a|q,W_t,H_t)||p_S(a|q,W_t,M_t)] L_current=KL[p_R(a|q,W_t)||p_S(a|q,W_t,M_t)]
min L_hist+L_nav s.t. E_{q∈Q_current}L_current≤ε, |M_t|=N

Navigation is the novelty; the perception–memory trade-off is its streaming constraint.

8. Qwen3.5-2B implementation

H_t=HiddenStates_Qwen3.5-2B(V_t,C_t) Z_t=Resampler(H_t), Z_t∈R^{L×2048}

Default: 16 latent tokens per chunk and 64 history tokens; evaluate L∈{8,16,32} and N∈{32,64,128}. No single-vector mean pooling.

frozen Qwen3.5-2B encoder → learned resampler / updater / navigator → projection + LayerNorm → frozen 7B/8B answer VLM

Qwen3-VL-Embedding-2B is an encoder baseline. The backbone is an implementation choice, not a contribution.

12. Metrics

Historical Gain=Acc(W_t,M_t)−Acc(W_t) Current Interference=Acc_current(W_t)−Acc_current(W_t,M_t) Net Memory Value=Historical Gain−λ·Current Interference
  • step-wise answer-support margin and monotonic progress rate;
  • operation-intervention sensitivity;
  • multi-hop / temporal question gain;
  • Answerability Collapse Rate;
  • memory tokens, read FLOPs, latency, and steps;
  • VideoMME retention.

13. Honest prior-work boundary

Prior work separately covers multi-step VideoQA attention, semantic-role-guided frame reasoning, recurrent question refinement, modern latent iterative retrieval, and multimodal embedding navigation. This work cannot claim the first latent navigation or multi-step VideoQA reasoning.

The strict combination not found in direct prior work is:

streaming query-independent fixed LLM-aligned semantic state + no discrete items / graph / retrieval + operation-conditioned navigation + step-wise answer-support progress + bounded current-scene interference
Go / No-Go

14. Evidence threshold

Go: under equal FLOPs, the semantic navigator beats deeper one-shot, recurrent attention, and latent deliberation; operations align with question types and shuffling hurts; support margin increases by step; and historical performance approaches or exceeds SelectStream while current perception is preserved.

No-Go: gains are explained by Qwen embeddings or depth; operations can be shuffled; progress loss is ordinary deep supervision; or the fixed state cannot approach SelectStream graph retrieval. Then the method is an old recurrent-attention network with a modern backbone.

One-sentence position

We introduce support-progressive semantic navigation over a fixed, query-independent, LLM-aligned multimodal history state, progressively transforming the question without retrieving discrete video evidence.
