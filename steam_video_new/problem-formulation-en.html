World-Model-Guided Multi-Hop Reasoning over Grounded Video Memory

Predict which reasoning hop will change future belief, execute one real evidence read, correct, and replan.

Current problem formulation · 2026-07-21 · 中文 · Repository overview

Core thesis

Reasoning must genuinely depend on the world model

Before every multi-hop reasoning step, an implicit world model (IWM) predicts how legal evidence-acquisition actions may change the future belief. A preference planner compares complete short trajectories, executes only the first hop of a preferred trajectory, observes real evidence, corrects the belief, and replans.

grounded L1/L1.5 evidence memory → bounded candidate reasoning hops → IWM imagined observation and belief transitions → ordinal trajectory preference → execute first hop → real evidence correction → replan

Paper-level contribution: action-conditioned prediction and model-predictive navigation of reasoning dynamics in belief space—not graph construction, generic retrieval, or numeric reward modeling.

1. Problem setting

Given a question q, a question-independent grounded video memory M, acquired evidence E_{1:t}, and a bounded read budget, choose the next reasoning action that is most likely to make the eventual evidence path preferable.

z_t = Enc(q, E_{1:t}, missing_t, alternatives_t, contradictions_t, budget_t) a_t ∈ A(M, z_t) T_θ(z_t,a_t) → (ô_{t+1}, Δẑ_{t+1}) Pref_φ(τ_i,τ_j | z_t) ∈ {prefer_left,tie,prefer_right,incomparable}

z_t is a latent, multi-token belief state. It need not be an explicit graph posterior. The IWM predicts an observation descriptor and belief change—not the next reasoning sentence and not evidence that may be used directly in the final answer.

2. Evidence memory: keep L1/L1.5

The current memory graph remains the evidence substrate because it provides addressable, source-traceable video observations. It is built without the future question or answer.

Typed L1.5 relations are candidates unless admitted by their required evidence gates. Noisy identity, state, or candidate-causal edges must not be treated as truth merely because they exist in the graph.

2.1 L1 storage contract

L1 is a question-independent Video_Skills-compatible ClueMemoryGraph. Each node stores one local, time-scoped observation rather than a reasoning conclusion.

Reliable composition edges include temporal_next, derived_from, entity_mention, state_of, and located_in. Native same_entity, same_object, reappears, before_after, state_change, supports_observation, contrasts_observation, causal_hint, and social_cue retain provenance but remain candidates unless their specific verifier admits them.

2.2 L1.5 correlation overlay

L1.5 reuses the same L1 node IDs and adds question-independent navigation edges for semantic/entity recurrence, state continuity or candidate transitions, transition support, responses, missing bridges, contradictions, and sparse verified explains/enables witnesses. Each edge records source/destination, relation type, candidate|verified|rejected|inconclusive status, evidence refs, candidate source, alignment, verifier result, and provenance. Embedding similarity proposes pairs; it does not prove relations.

L1/L1.5 never stores the correct answer, hidden clue identity, question-conditioned belief, IWM imagination, predicted belief delta, planner trajectory, reward/utility/Q-value, GTSAM posterior, or final claim. These belong to hidden evaluation, latent belief, or the executed L2 trace.

3. Reasoning actions

An action is a reasoning/evidence query, not a physical action:

A = {semantic, temporal_before, temporal_after, same_entity, state_check, candidate_cause, effect, bridge, counterevidence, verify, stop_or_abstain}

The main method has one active current-node cursor. Ordinary navigation actions use that cursor as their only source; acquired nodes remain in belief/frontier history and can be revisited through an explicit BACKTRACK/SHIFT_FOCUS operation. This avoids expanding all frontier sources against all graph targets.

A_t = outgoing_temporal(current) ∪ outgoing_correlation(current) ∪ semantic_probe(current, every visible retained node) ∪ backtrack(acquired frontier history) ∪ {stop, answer, abstain}

A deterministic Graph Action Compiler enumerates actions from endpoint validity, streaming visibility, relation status, provenance, executor availability, and budget. It never filters by question relevance. A virtual query root exposes START_AT(node) for every retained node at the first step. Fixed-capacity L1 keeps this set bounded, so the Full-IWM arm uses no embedding Top-K; Top-K is an explicit retrieval baseline only.

4. Short-horizon model-predictive reasoning

  1. Compile every legal action from the single current-node cursor and fixed L1.5 graph.
  2. Imagine horizon-one or horizon-two categorical transitions for each action.
  3. Compare complete candidate trajectories pairwise.
  4. Execute only the first action of a uniquely preferred trajectory.
  5. Discard imagined observations, read real evidence, update belief, and replan.
τ* = PreferredTrajectory({Rollout_T(z_t,a)}_a) a_t* = First(τ*) o_{t+1} = Execute(M,a_t*) z_{t+1} = Update(z_t,a_t*,o_{t+1})

The world model is useful when a low-immediate-gain bridge hop unlocks a decisive second hop. This delayed effect is the principal distinction from reactive retrieval or immediate information-gain ranking.

The learned IWM predicts all legal first hops in one batched graph/tensor forward. Horizon two may remove only strictly dominated first hops before expanding every second hop from the remaining partial-order set; it does not use fixed-K beam pruning.

Non-heuristic boundary

5. What may and may not choose the next hop

Allowed roleForbidden role in the main arm
Embedding similarity proposes candidatesHighest similarity automatically wins
Graph/factor constraints reject illegal or unsupported hopsFactor posterior or edge priority ranks the winner
Lexical/temporal rules define explicit baselinesHidden fallback decides ties in the IWM arm
IWM predicts categorical future belief effectsModel emits scalar reward, utility, Q-value, confidence, or probability

tie and incomparable must trigger further evidence, additional comparison, or abstention. Candidate order must be permutation invariant.

6. Keep the model input bounded

The IWM/planner does not receive the entire video, raw embedding matrix, hidden answers, or unconsolidated history. Because L1 memory has fixed capacity, it consumes the complete retained graph without Top-K truncation: question and belief tokens, the current cursor node's key and acquired value, every retained node key, all retained temporal/correlation edges, all legal cursor actions, recent history, and budget status.

surprise-written, fixed-capacity L1 nodes + complete retained temporal/correlation graph + one current-node cursor → all legal actions in one batched IWM forward → partial-order planner

Unread target nodes expose compact key/address representations; their full evidence values are revealed only after execution. Qwen/Qwen3-VL-Embedding-2B vectors remain in sidecars and serve as semantic action features—not a main-arm ranking gate, reward, or supervision.

7. Belief correction and the GTSAM backup

The main method uses a latent belief update after each real observation. GTSAM/factor graph is retained as an optional correction backend, baseline, diagnostic oracle, teacher, and visualization tool.

default: iwm_belief_only optional correction: iwm_with_gtsam_backup baseline/ablation: gtsam_always

Only executed, provenance-bearing, categorically verified observations may become factors. Imagined rollouts never enter persistent belief. Backup activation uses explicit categorical conditions such as identity ambiguity, contradiction, state-history conflict, or failed correction—not a hand-set posterior threshold.

GTSAM does not generate actions, traverse the graph, rank candidates, predict transitions, or ground the final answer. The main contribution must survive without it.

Supervision

8. Where the learning signal comes from

CG-Bench supplies human clue intervals and terminal answers. Executing a clue read yields categorical progress such as advances_required_clue_coverage, partial, or complete. Complete-clue versus leave-one-clue-out trajectories provide an ordinal preference.

  • Unmatched L1.5 candidates remain unlabeled; they are not fabricated semantic negatives.
  • Qwen-VL produces grounded observation descriptors, not GT relation labels.
  • GPT-5.6 visual review is optional diagnosis and does not overwrite CG-Bench ground truth.
  • Identity, state-transition, causal, and counterevidence relations need their own trusted labels.
  • Validation/test videos are never used for training.

Sibling branches executed from the same immutable checkpoint supervise action-conditioned observation and belief-delta prediction, and give pairwise trajectory comparisons without assigning absolute utility.

9. Post-training strategy

  1. SFT on reviewed categorical observation descriptors and realized belief deltas.
  2. Pairwise preference optimization on locked sibling trajectories.
  3. Only after label quality is established, optionally test group-relative ordinal optimization.

No LLM/VLM produces a numeric reward. A future GRPO-style optimizer may derive internal group-relative advantages from categorical ordering, but the data contract contains no weighted heuristic reward and no model-generated score. GPT-OSS-120B is currently an inference/data-gathering baseline; training has intentionally not started.

Decisive experiment

10. Prove causal dependence on the IWM

Hold question, evidence memory, candidate set, planner, and read budget fixed. Change only the world-model condition:

  1. full delayed-belief IWM;
  2. no world model;
  3. shuffled IWM predictions;
  4. frozen IWM;
  5. immediate-effect-only;
  6. oracle clue ceiling, reported only as a diagnostic upper bound.

Report answer accuracy, evidence completeness, read efficiency, action divergence, categorical transition accuracy, and delayed two-hop success separately. Do not collapse them into one lexicographic gate or scalar utility.

Go / No-Go

11. Evidence required for the claim

Go: the full IWM improves delayed multi-hop success under matched budgets; removing, freezing, or shuffling its predictions changes actions and hurts outcomes; prediction error correlates with navigation failure; and gains persist under candidate-order permutation.

No-Go: the same action sequence appears without the IWM, graph/embedding heuristics explain the gain, imagined evidence leaks into answers, candidate recall is too low to expose the required clue, or only immediate-gain cases improve.
