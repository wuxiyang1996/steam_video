Support-Progressive Navigation over Fixed Streaming Semantic Memory

Semantic-state navigation without discrete evidence retrieval for streaming Video QA

Problem formulation · 2026-07-17 · 中文

Core problem

How can a question progressively find an answer inside a non-retrievable continuous history state?

A streaming Video-LLM must compress video-caption history under a fixed budget. We retain no frames, segments, nodes, or graph: history exists only in one fixed, LLM-aligned embedding state. Once a question arrives, the system cannot retrieve an explicit evidence chain; it must progressively transform the question representation within the continuous state.

How can a streaming Video-LLM navigate a fixed, query-independent multimodal semantic state to progressively acquire answer-supporting information, without retrieving discrete memory items?

The main contribution is navigation, not memory architecture: each step selects a semantic operation, reads complementary information from the same continuous state, and increases support for the correct answer over plausible alternatives.

1. Problem setting: fixed query-independent multimodal semantic state

Z_t = Fuse(E_V(V_t),E_C(C_t)) M_t = U_φ(M_{t-1},Z_t), M_t∈R^{N×d}, N=constant

M_t is written online before any future question and jointly encodes entities, events, states, temporal relations, caption/ASR semantics, visual-only details, and cross-modal conflicts.

History contains no independent evidence items, frames, clips, caption entries, timestamps, pointers, provenance, nodes, edges, growing bank, Top-K retrieval, or raw-video replay.

The claim is about answer-supporting latent information, not grounded or source-traceable evidence.

2. Streaming interface: decouple current perception and history

Current path: W_t = RecentWindow(Z_{t-w:t}) History path: M_t = U_φ(M_{t-1},Z_{t-w-1})

W_t retains raw/lightly compressed recent tokens for object, attribute, action, OCR, and fine detail. M_t represents only older history. This split is a streaming interface, not the novelty.

3. Main method: Semantic-State Navigator

Initialize the query state and perform at most K operation-conditioned reads over fixed history:

u_0=E_Q(q) π_k=p_ψ(o_k|u_{k-1},q) e_k=Σ_o π_{k,o}e_o^{op} r_k=CrossAttn(u_{k-1}+e_k,M_t) u_k=GRU(u_{k-1},r_k,e_k)

The first version uses one shared reader and six lightweight operation embeddings:

O={GROUND_ENTITY, RESOLVE_EVENT, TRACE_STATE, LINK_TEMPORAL, CHECK_CONFLICT, COMPOSE}

Operations are not agents or expert networks. They condition what semantic relation the shared reader should decode at each step.

4. Navigation supervision: support progress, not attention depth

m_k=s(a^+|u_k,W_t)−max_{a^-∈A^-}s(a^-|u_k,W_t)

Each step should improve discrimination between the correct answer and the strongest plausible alternative:

L_progress=Σ_k max(0,m_{k-1}+δ−m_k)

Complementarity discourages repeated reads of the same latent direction:

L_comp=Σ_{k>1}Overlap(α_k,α_{k-1})
L_nav=L_QA+λ_pL_progress+λ_cL_comp+λ_oL_operation

L_operation may use weak supervision from question semantics or teacher traces but must not become a hard-coded program. If operation shuffling has no effect, the semantic-navigation claim fails.

Go / No-Go

14. Evidence threshold

Go: under equal FLOPs, the semantic navigator beats deeper one-shot, recurrent attention, and latent deliberation; operations align with question types and shuffling hurts; support margin increases by step; and historical performance approaches or exceeds SelectStream while current perception is preserved.

No-Go: gains are explained by Qwen embeddings or depth; operations can be shuffled; progress loss is ordinary deep supervision; or the fixed state cannot approach SelectStream graph retrieval. Then the method is an old recurrent-attention network with a modern backbone.

One-sentence position

We introduce support-progressive semantic navigation over a fixed, query-independent, LLM-aligned multimodal history state, progressively transforming the question without retrieving discrete video evidence.

Alternative track

15. Causality-aware latent memory (SelectStream-adjacent)

Unified framing: nodes store local visual evidence; uncertain latent relations encode explanatory dependencies; consolidation preserves reasoning paths; the query evolves with observed evidence and the current causal hypothesis.

How can a bounded latent memory preserve temporal and explanatory reasoning paths under continual consolidation, while supporting closed-loop query-dependent navigation?

Claim carefully: latent explanatory dependency / causal-support graph — not a true causal graph from observational video.

15.1 Node memory + latent causality

m_i=(h_i,τ_i,p_i) c_ij=(r_ij,u_ij,d_ij)=f_causal(h_i,h_j,Δτ_ij,…) G=(M,C)

r: relation embedding; u: uncertainty; d: direction. Do not build full O(N²) pairwise causality. Online: cheap Top-K candidates (recency, entity, semantic, state, causal frontier) → relation inference only on P_j → O(NK), K≪N. Long-range needs: causal landmarks + hierarchical summaries, not all-node scans.

15.2 Consolidation: not “delete lowest causality”

Causal utility helps, but isolated / unresolved / factual nodes can still matter; the relation model errs; many QA types need facts, not chains. Multi-objective importance + three ops:

I_i=λ_s I_i^sem+λ_t I_i^temp+λ_c I_i^causal+λ_q I_i^query+λ_u I_i^unc ops ∈ {keep, merge, abstract, delete}
  • Delete — redundant, low causal contribution, low uncertainty, non-unique.
  • Merge — same-state persistence; keep time span.
  • Abstract — compress a causal motif into a summary node with provenance (strongest new op).

Protect bridges, unique state transitions, high-influence causes, and unresolved hypotheses. Strongest novelty among the three: reasoning-preserving consolidation.

15.3 Query over time: do not glue one embedding

z_t=[z_t^q; z_t^e; z_t^c; z_t^r] z_t^c=PathEncoder(current evidence path) a_t∈{retrieve-sem, follow-cause/effect, find-bridge, seek-counter, backtrack, stop}

Parts: question / collected evidence / current causal-path hypothesis / missing requirement. Trajectory: match → anchor effect → search cause → complete bridge → verify / counter. Next hop depends on the actual retrieval outcome (closed-loop), not a one-shot symbolic program.

15.5 Why a world model: delayed utility & irreversibility

Belongs only on this causality-aware track: the continuous-state track has no discrete evidence actions or retrieval transitions, so a world-model framing there would be artificial. This is a short-horizon belief-transition / reasoning-utility model — not a pixel-level video world model.

The two strongest motivations:

  • Delayed utility of bridge evidence. A retrieval step may provide little immediate relevance or answer gain, yet unlock the next temporal or causal hop. This cleanly distinguishes the method from greedy iterative retrieval. Example: e1 return to room → e2 empty pocket (bridge) → e3 keys left in room.
  • Irreversibility under bounded memory. Poor navigation wastes retrieval budget; incorrect merging or deletion can permanently break a reasoning path. The same utility model can therefore guide both navigation and consolidation.

Paper-level claim: Existing iterative retrieval is reactive and optimizes locally useful evidence. We learn a short-horizon belief-transition model that predicts the delayed reasoning utility of semantic, temporal, and causal navigation actions, while estimating the path loss caused by memory consolidation.

Greedy retrieval: a_t = arg max_a V(s_{t+1}) Our planning: a_t = arg max_a E[V(s_{t+K})∣s_t,a]

K stays small (likely one or two imagined retrieval steps) so the model stays lightweight and the claim remains defensible.

learn T_φ(b_{t+1}∣b_t,a_t), b_t=P(relevant path∣q,E_{1:t}) r_t=Δchain completeness+Δanswerability−cost

15.6 Implicit world state for video-graph navigation

At the method level, multi-hop reasoning is modeled as action-conditioned dynamics in an abstract latent state space. The latent state need not decode into a fixed belief schema, evidence list, or webpage-like state:

z_t=Enc_θ(q,h_t) p_φ(ẑ_{t+1},ô_{t+1}|z_t,a_t) z_{t+1}=U_ψ(z_t,a_t,o_{t+1})

The first transition is an execution-time prior over how a reasoning action may reshape the trajectory and what evidence it may reveal. After the real retrieval/navigation action returns observation o_{t+1}, the updater forms the posterior reasoning state. This distinction prevents imagined evidence from being treated as observed fact.

For the video-graph instantiation, the latent state is conditioned on the following information without requiring it to be represented as explicit slots:

  • Ot — current observation: current/recent video event, visible entities, actions, and state changes;
  • E1:t — reasoning history: grounded evidence acquired so far and the actions that acquired it;
  • Ht — active hypotheses: candidate reasoning chains and competing answer explanations;
  • gt — next reasoning need: the missing entity, temporal link, explanatory bridge, counterevidence, or verification step;
  • Bt — budget: remaining retrieval calls, latency, and memory/navigation cost.

The navigator maintains a probability distribution over reasoning hypotheses and graph locations rather than one path or a fixed-size beam:

b_t(H,v)=P(H_t=H,v_t=v | q,E_{1:t}) π_t(a,v'|H,v)=P(a_t=a,v_{t+1}=v' | z_t,H,v) b_{t+1}(H',v')=Σ_{H,v,a} b_t(H,v)π_t(a,v'|H,v)T_φ(H'|H,v,a,v')

Each hop distributes probability mass in parallel over semantic neighbors, temporal forward/backward nodes, explanatory predecessors/effects, bridges, and counterevidence. Compatible successors merge by accumulating probability; contradictions reduce or split mass; alternative chains remain alive in proportion to posterior support. Computation can use sparse soft routing such as entmax or adaptive cumulative-probability truncation, so the represented uncertainty is probabilistic even when negligible mass is omitted for efficiency. There is no method-level fixed number of chains or expansions.

The world model predicts the next multi-hop reasoning state rather than an evaluation metric. A transition may ground an entity, establish temporal order, extend an explanatory link, expose a missing bridge, reveal a contradiction, verify a chain, or make the answer ready. The following reasoning-stage variable is an interpretable probe or auxiliary head, not the definition of z_t:

ρ_t∈{GROUND, TEMPORAL_LINK, EXPLANATORY_LINK, FIND_BRIDGE, SEEK_COUNTER, VERIFY_CHAIN, ANSWER, ABSTAIN}

Short imagined rollouts compare parallel expansion sets and their successor beams by whether they complete the required reasoning roles, resolve missing links, preserve genuinely different hypotheses when uncertainty remains, and reach a verified answer state with low cost. Causal/explanatory coherence, uncertainty calibration, temporal correctness, and semantic relevance are validation axes for these predicted reasoning transitions—not explicit world-state slots. Recall, relation F1, calibration, and answer accuracy likewise remain evaluation measures only.

15.7 Boundary against reasoning world models and latent retrieval

Several neighboring lines cover important parts of this formulation, so the contribution cannot be “using a world model for reasoning” or merely “latent state transitions.”

  • RAP repurposes an LLM as a world model and uses MCTS to plan over explicit reasoning states. It establishes reasoning-as-world-model planning, but its transitions are primarily language-space reasoning or environment states rather than an implicit belief over externally acquired video evidence.
  • Coconut feeds continuous hidden states back into the model and can retain multiple alternative next reasoning steps. It establishes latent multi-path reasoning, but does not center action-conditioned external evidence acquisition or observation-driven updates over a video graph.
  • CTRLS explicitly models CoT as an MDP with probabilistic latent state transitions and epistemic uncertainty. It is therefore a close precedent for latent transition dynamics; our distinction must come from evidence-grounded video navigation, not from the latent-MDP formulation itself.
  • Agent Learning via Early Experience trains the same language-agent policy to predict a textual next environment state from a state–action pair, using consequences of expert, policy-proposed, and alternative actions as auxiliary supervision before expert fine-tuning. Its implicit world model is internalized into policy parameters and is not separately rolled out for test-time planning. Our setting instead predicts transitions over latent evidence-conditioned reasoning beliefs and explicitly compares probabilistic navigation futures at inference.
  • Stop-RAG learns forward-looking value for whether iterative retrieval should continue. Its principal control is stopping, rather than predicting which semantic, temporal, explanatory, bridge, or counterevidence expansion will transform the next reasoning state.
  • LAnR performs retrieval with latent queries and learns a head for whether more evidence is needed. It is closer to latent retrieval control than to a predictive transition model over future evidence observations and parallel reasoning hypotheses.

Defensible position: learn an evidence-conditioned implicit belief-transition model for streaming video-graph QA that predicts how probabilistic parallel semantic, temporal, and explanatory navigation will change the next multi-hop reasoning state after real evidence is observed. The empirical comparison must include RAP-style explicit planning, latent reasoning, direct action ranking, adaptive stopping, and ordinary iterative retrieval.

Higher-level framing: implicit world modeling for abstract reasoning dynamics. We model multi-hop reasoning as action-conditioned transitions in a latent state space, where the world model predicts how intermediate reasoning actions reshape the trajectory toward an answer. This is motivation and method abstraction; the paper-level novelty must still be established by evidence-conditioned video navigation, observation-grounded posterior updates, delayed bridge utility, and test-time planning.

Training implication from Early Experience: at each real video-graph reasoning checkpoint, execute expert, current-policy, and admissible alternative navigation actions against the graph and record (z_t,a_t,e_{t+1},z_{t+1}). Train the transition model to predict both the evidence observation and updated latent reasoning state, including outcomes of wrong or locally attractive actions. This one-step supervision initializes dynamics, but does not establish the paper claim by itself. The decisive result must show that test-time rollout over the learned transition model selects delayed-utility bridge evidence and outperforms the same policy trained with next-state prediction but deployed without planning.

15.8 Multi-chain search → answer by calibrated confidence

The world model generates, expands, and compares multiple reasoning chains; the answer is not decided by a single path, but by aggregated support and calibrated confidence over candidate chains.

The world model performs test-time search over multiple temporal-causal reasoning chains, while a calibrated verifier aggregates chain-level evidence into answer confidence and controls whether to continue, answer, or abstain.

Roles: the world model predicts transition probabilities over parallel node expansions and reasoning hypotheses; the verifier updates and calibrates their posterior mass; answer confidence decides when to output.

Hypotheses. After anchoring, maintain H_t={H_t^1,…,H_t^B} with beam B≈3–8:

H^k=(e_1,r_{12},e_2,…,e_n) r ∈ {semantic, temporal, state-transition, explanatory/candidate-causal}

Example for “Why return to kitchen?”: H_1 left cup→noticed missing→returned; H_2 heard noise→returned; H_3 talk to someone→returned. Soft edges may live underneath; reasoning keeps sparse, auditable hypotheses.

Three confidence layers (do not collapse):

  1. Edge: c_{ij}^r=P(r_{ij}∣e_i,e_j).
  2. Chain: C(H)=Verifier(q,H) — evidence, temporal, causal/explanatory, grounding, minus contradiction and missing-link penalties (not a product of edge probs).
  3. Answer: for candidates y, aggregate supporting chains with redundancy correction:
S(y)=log Σ_{H∈H(y)} exp(C(H)) P(y∣q,E)=softmax_y S(y)

Final confidence comes from evidence chains, not VLM token probabilities.

When to answer — all of: P(y_max)>τ_ans, margin vs runner-up, coverage of required roles, no strong unresolved contradiction. Else:

d_t ∈ {continue, verify, answer, abstain} (H^*,a^*)=arg max_{H,a} E[ΔC_answer+ΔC_chain−λcost∣H,a]

Actions: temporal back/forward, causal predecessor/effect, bridge, counter-evidence, verify edge. Bridge steps may raise chain expandability without immediate answer gain — exactly §15.5 delayed utility.

Pipeline: streaming video → bounded latent temporal-causal memory → multi-hypothesis init → world-model rollout → retrieve real evidence → update edge/chain confidence → compare support & contradictions → answer / continue / abstain.

15.9 Three-day video graph + world-model navigation sprint

The sprint builds a small temporal-explanatory event graph directly over 20–50 short videos, then tests whether one- or two-step world-model lookahead improves navigation over that graph. Edges are candidate causal-support relations inferred from observational video, captions, subtitles, and event order; they are not claims of true causal identification. Existing Video Skills infrastructure may be reused for decoding, segmentation, captions, and evaluation, while the method and runtime remain separate.

  1. Day 1 — video event graph: segment each video into events; extract entities, actions, state changes, and timestamps; and create sparse candidate edges of type temporal-next, same-entity, state-transition, explanatory-support, and contradiction. Use cheap retrieval to propose Top-K neighbors and a VLM/teacher to label relation type, direction, uncertainty, and a short warrant. Manually audit a sample of edges.
  2. Day 2 — world-model navigator: define actions {retrieve-semantic, follow-temporal, follow-explanatory, find-bridge, seek-counter, stop}. From question-conditioned checkpoints, train or calibrate a lightweight transition model for one- or two-step navigation. Maintain posterior mass over chains and graph nodes, route to multiple successors in parallel, merge compatible states by probability accumulation, and use adaptive probability-mass truncation only for computational efficiency.
  3. Day 3 — matched-budget evaluation: compare semantic Top-K retrieval, greedy one-step navigation, direct action ranking without transitions, beam search without a learned world model, oracle graph paths, and world-model navigation. Measure answer accuracy, supporting-event Recall@K, bridge retrieval, chain completeness, relation precision, latency, and regret to the oracle. Shuffle edges and transition targets as causal controls.

Go: audited candidate edges reach at least 70% precision; at least 20% of valid questions require a bridge event or delayed-utility hop; and world-model navigation improves supporting-event Recall@K by at least 10 absolute points or answer accuracy by at least 5 points over both greedy and direct-ranking baselines under equal retrieval calls. Edge/transition shuffling must materially reduce the gain. No-Go: the graph is too noisy, most questions are solved by direct semantic retrieval, a non-predictive beam/direct ranker matches the world model, or gains vanish under equal budgets.

15.10 Unifying world models, factor graphs, and causal reasoning

This subsection states the higher-level research framing that organizes §15.5–§15.9. It does not replace the paper-level claim of evidence-conditioned video-graph navigation; it clarifies what kind of world model, graph, and causality we mean.

15.10.1 Starting question: a world model for abstract problem solving?

Classical world models learn physical or game transitions:

s_{t+1}=F(s_t,a_t)

The broader question is whether multi-hop reasoning, evidence acquisition, and problem solving can be cast as a dynamical system whose state evolves with reasoning actions and new evidence:

z_{t+1}=F_θ(z_t,a_t,o_{t+1})
  • z_t: current problem-solving / belief state;
  • a_t: reasoning, retrieval, verification, or backtracking action;
  • o_{t+1}: new evidence obtained after the action;
  • z_{t+1}: updated problem-solving state.

Prior work covers language-space planning, latent reasoning, iterative retrieval, and agent world modeling, but rarely learns how a reasoning action changes evidence state, hypotheses, uncertainty, and future solvability. Directly modeling a general abstract problem-solving state is too broad: the hard questions are what the state variables are, what the actions are, where transition supervision comes from, how next states from different valid paths unify, and how to verify that a latent state truly represents problem solving. A realistic starting point is multi-hop video reasoning, where entities, events, time, and evidence are comparatively well structured.

15.10.2 Why not an ordinary reasoning graph?

Ordinary GraphRAG, knowledge graphs, or graphs-of-thought typically connect documents, entities, events, thoughts, or retrieved evidence by semantic similarity, entity overlap, temporal adjacency, or retrieval links. They answer “which items are related?” We instead want:

  • which variables remain unknown;
  • what constraints current evidence places on those variables;
  • which hypotheses remain uncertain;
  • how the global belief should update after a new factor arrives.

The core is therefore not only navigation on a graph, but continual inference over structured variables and constraints.

15.10.3 Role of the factor graph

A factor graph decomposes the joint into local constraints:

p(X∣E) ∝ ∏_i φ_i(X_i,E_i)

Variable nodes are unknowns; factor nodes are evidence, constraints, dependencies, or transitions. New evidence reopens global posterior computation, so later evidence can revise earlier hypotheses. In multi-hop video reasoning, variables may include entity identity, event occurrence, object state, temporal location, causal relation, bridge entity, intermediate subanswer, and final answer. Factors may include:

  • φ_visual — whether a clip supports an event or state;
  • φ_identity — whether entities across clips are the same;
  • φ_temporal — before / after / during;
  • φ_causal — whether one event causes or enables another;
  • φ_consistency — agreement among evidence or hypotheses;
  • φ_answer — compatibility of intermediate variables with the final answer.

Multi-hop reasoning then means: continuously acquire new evidence factors and perform incremental inference over latent variables.

15.10.4 Joint modeling of reasoning and evidence

We do not only “use a factor graph for reasoning.” More precisely, the factor graph jointly models reasoning, evidence acquisition, and belief update:

G_t →[reasoning] a_t →[evidence acquisition] e_{t+1} →[factor construction] φ_{t+1} →[global inference] G_{t+1}

Reasoning chooses which variable to resolve, which temporal window to inspect, which entity to track, which temporal/causal link to verify, which reasoning gap to fill, and whether to backtrack or stop. New evidence is not merely appended to memory; it becomes a new factor that changes belief over the whole graph. Preferred descriptions:

  • Reasoning as active constraint acquisition;
  • Joint evidence acquisition and reasoning over a dynamic epistemic factor graph.

15.10.5 Combining factor graphs with world models

The factor graph can serve as the structured state of the world model. Instead of only learning z_{t+1}=F_θ(z_t,a_t), the structured version learns:

G_{t+1}=F_θ(G_t,a_t,o_{t+1})

G_t is the current posterior over the world and the question: which entities/events are resolved, which relations remain unknown, which evidence supports or refutes a hypothesis, what the answer distribution is, and what constraint should be acquired next. The world model has two kinds of transition factors:

  • World-state transition φ_world(X_t,u_t,X_{t+1}) — e.g. person presses switch → light turns on;
  • Belief-state transition φ_belief(B_t,a_t,e_{t+1},B_{t+1}) — e.g. inspect earlier clip → resolve entity identity → reduce answer uncertainty.

Thus the world model predicts not only the video future, but how the problem-solving graph changes after acquiring a piece of evidence — aligning with the belief-transition model in §15.5–§15.6.

15.10.6 SLAM analogy (factor graphs / GTSAM)

Frank Dellaert’s factor-graph / GTSAM view is a useful analogy, not a claim that we implement full GTSAM:

SLAMReasoning + evidence
Robot poseCurrent observation / reasoning location
LandmarkEntity, event, unknown fact, or subgoal
Measurement factorVideo evidence factor
Odometry factorTemporal or reasoning-transition factor
Loop closureNew evidence re-constraining earlier hypotheses
SmoothingLater evidence revising earlier belief
Active SLAMActively choosing the next most valuable evidence

The key value is incremental smoothing. Autoregressive reasoning A→B→C→D often continues on an early error; a factor graph allows later evidence to trigger global posterior update and revise earlier variables — reasoning loop closure.

15.10.7 Factor graphs vs causality

A factor graph is not a causal graph. A factor φ(X,Y) encodes local compatibility or dependence, not whether X→Y or Y→X. Factor graphs excel at evidence fusion, uncertainty, local constraint decomposition, global consistency, and posterior correction. Causal semantics must be injected by variable definitions and specific causal / temporal / transition factors. The system may mix non-causal identity factors, temporal factors, evidence-support factors, consistency factors, causal-mechanism factors, and action-conditioned transition factors. Accurate label:

Epistemic factor graph with causal-temporal and transition factors

— not “every edge is causal.”

15.10.8 Causality, causal inference, and causal reasoning

  • Causality — generative mechanisms in the world, e.g. Y=f(X,U) or press switch → light on.
  • Causal inference — identifying / estimating structure or effects from observational or interventional data, e.g. P(Y∣do(X=x)).
  • Causal reasoning — prediction, intervention, and counterfactual rollouts on an assumed or learned causal model.

Our near-term goal is not classical causal-effect estimation. It is the two-stage pipeline below: recover usable causal-temporal structure from video evidence, then reason and navigate with that structure as world-model state.

15.10.9 Two-stage framework

Stage 1 — induce a causal-temporal evidence graph. From streaming video and the question, incrementally build G_t=(V_t,E_t) with nodes for entities, events, states, evidence, hypotheses, and unresolved variables; and edges/factors for precedes, during, same-entity, supports, contradicts, causes, enables, and state transition. Goal: E_{1:t},Q → G_t.

Stage 2 — treat the graph as world-model state. Learn G_{t+1}∼T_θ(G_t,a_t) (with real observation updates as in §15.6) and use it for causal reasoning, multi-hop completion, evidence navigation, hypothetical rollout, answer prediction, and failure recovery. Actions include inspect a temporal window, track an entity, verify an event, follow a causal predecessor, search for a consequence, test a hypothesis, and acquire a missing factor.

Causal-temporal graph induction → Factor-graph inference → Graph world modeling → Multi-hop reasoning and evidence acquisition

15.10.10 Why start from multi-hop video reasoning

Video supplies relatively clear structure: observable time, trackable entities, localizable events, extractable state changes, clip-grounded evidence, and multi-hop questions with explicit temporal/entity/event chains. Example: “What did the person who took the cup do before entering the room?” requires locating the cup-taking event, identifying the actor, tracking that entity earlier, locating room entry, finding the preceding action, and checking identity/temporal consistency — naturally a chain of identity, event, and temporal constraints. Text multi-hop QA (e.g. MuSiQue / 2Wiki) remains a useful mechanism sandbox for belief transitions and delayed bridge utility, but paper novelty still requires the video evidence setting (§15.7).

15.10.11 Realistic first system

v1 should not claim a general reasoning world model or a full GTSAM-style stack. Build instead: (1) a dynamic evidence factor graph; (2) a small set of well-defined variables; (3) learned visual, identity, temporal, and causal factors; (4) message passing or approximate posterior inference; (5) a controller that chooses the next video evidence; (6) global belief revision after each new factor. Key experimental questions:

  • Does global graph update correct early errors better than append-only memory?
  • Does active factor acquisition beat top-k retrieval under equal observation budget?
  • Does the factor graph help more on cross-time, cross-event, and bridge-entity questions?
  • Do causal-temporal factors improve multi-hop chain consistency?
  • Can later evidence revise early wrong entity/event bindings?

15.10.12 Research position

Do not claim: “General causal world model for abstract reasoning.” Prefer:

  • A dynamic causal-temporal factor graph for joint evidence acquisition and multi-hop video reasoning.
  • A structured graph world model that incrementally integrates video evidence, revises latent event hypotheses, and actively navigates causal-temporal reasoning chains.

Longer-term vision: cast problem solving as active constraint acquisition, global belief update, and action-conditioned world-model planning over a dynamic epistemic factor graph.
