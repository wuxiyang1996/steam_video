基于真实视频证据记忆的世界模型引导多跳推理

预测下一跳推理会如何改变未来 belief，执行一次真实证据读取，修正并重新规划。

当前问题定义 · 2026-07-21 · English · 仓库总览

核心命题

推理必须真正依赖 world model

每一步多跳推理之前，implicit world model（IWM）预测各个合法证据获取 action 将怎样改变未来 belief。Preference planner 比较完整的短轨迹，只执行获偏好轨迹的第一跳；获得真实证据后修正 belief，再重新规划。

问题无关的 L1/L1.5 evidence memory → 有界候选 reasoning hops → IWM 想象 observation 与 belief transition → 序数 trajectory preference → 只执行第一跳 → 真实 evidence correction → 重新规划

论文级贡献：在 belief space 中预测 action-conditioned reasoning dynamics，并用 model-predictive planning 导航下一跳；不是 graph construction、普通 retrieval 或数字 reward modeling。

1. 问题设定

给定问题 q、问题无关的真实视频记忆 M、已读取证据 E_{1:t} 和有限读取预算，选择最可能使最终证据轨迹更优的下一步 reasoning action。

z_t = Enc(q, E_{1:t}, missing_t, alternatives_t, contradictions_t, budget_t) a_t ∈ A(M, z_t) T_θ(z_t,a_t) → (ô_{t+1}, Δẑ_{t+1}) Pref_φ(τ_i,τ_j | z_t) ∈ {prefer_left,tie,prefer_right,incomparable}

z_t 是 multi-token latent belief state，不必等同于显式 graph posterior。IWM 预测 observation descriptor 和 belief change，不预测下一句 reasoning text，也不能生成直接进入最终答案的想象证据。

2. Evidence memory：保留 L1/L1.5

当前 memory graph 继续作为 evidence substrate，因为它能提供可寻址、可追溯来源的视频 observation；构建时不能读取未来问题或答案。

层级职责研究定位
L1真实 visual/text observations、时间戳、provenance、embedding基础设施
L1.5event 与候选 temporal、identity、state、dependency、bridge、contradiction relation证据寻址和候选生成
Latent belief问题条件下的 competing interpretations、missing links 和 answerability主方法状态
L2已执行 action、真实 observation、realized delta 和决策审计轨迹记录，不是 world model

L1.5 typed relation 在通过相应 evidence gate 前只是 candidate。Identity、state 或 candidate-causal edge 不能因为已经写入图就被当成事实。

2.1 L1 存储协议

L1 是 question-independent、兼容 Video_Skills 的 ClueMemoryGraph。每个 node 存一条局部、有时间范围的 observation，而不是 reasoning conclusion。

Node/字段存储内容
公共字段稳定 node/video ID、node type、grounded text descriptor、modality、time span、clip/local ID、evidence refs、source、producer、provenance、visibility 和可选 embedding sidecar reference
clip可寻址视频区间、粒度和 segmentation policy
observation/event直接可见/可读的局部描述或 atomic action，不存推断出的 motive
entity_mention局部 mention ID、entity type、可见属性、时间和 evidence；不自动声明跨 clip identity
stateSubject、attribute、value、polarity、temporal scope 和 evidence
dialogue_span/OCR带真实 modality 的 time-aligned text；字幕不能冒充直接 audio observation

可靠 composition edges 包括 temporal_next、derived_from、entity_mention、state_of 和 located_in。Native same_entity、same_object、reappears、before_after、state_change、supports_observation、contrasts_observation、causal_hint 和 social_cue 保留 provenance，但只有通过各自 verifier 后才能提升。

2.2 L1.5 correlation overlay

L1.5 复用同一批 L1 node IDs，并增加 question-independent navigation edges：semantic/entity recurrence、state continuity 或 candidate transition、transition support、response、missing bridge、contradiction，以及稀疏 verified explains/enables witness。每条 edge 记录 source/destination、relation type、candidate|verified|rejected|inconclusive status、evidence refs、candidate source、alignment、verifier result 和 provenance。Embedding similarity 只提出 pair，不能证明 relation。

L1/L1.5 永不保存 correct answer、hidden clue identity、question-conditioned belief、IWM imagination、predicted belief delta、planner trajectory、reward/utility/Q-value、GTSAM posterior 或 final claim。这些分别属于 hidden evaluation、latent belief 或 executed L2 trace。

3. Reasoning actions

Action 表示 reasoning/evidence query，不是机器人在物理世界中的动作：

A = {semantic, temporal_before, temporal_after, same_entity, state_check, candidate_cause, effect, bridge, counterevidence, verify, stop_or_abstain}

主方法维护一个 active current-node cursor。普通 navigation action 只以该 cursor 为 source；已读取 nodes 保留在 belief/frontier history，需要时通过显式 BACKTRACK/SHIFT_FOCUS 返回，不能把全部 frontier sources 与全部 targets 做笛卡尔积展开。

A_t = outgoing_temporal(current) ∪ outgoing_correlation(current) ∪ semantic_probe(current, 每个可见 retained node) ∪ backtrack(acquired frontier history) ∪ {stop, answer, abstain}

确定性的 Graph Action Compiler 只根据 endpoint validity、streaming visibility、relation status、provenance、executor availability 和 budget 枚举 actions，不按 question relevance 过滤。初始步骤使用 virtual query root，为每个 retained node 提供 START_AT(node)。由于 L1 容量固定，Full-IWM arm 不使用 embedding Top-K；Top-K 只作为显式 retrieval baseline。

4. 短视界 model-predictive reasoning

  1. 从单一 current-node cursor 和固定 L1.5 graph 枚举全部合法 actions；
  2. 为每个 action 想象 horizon-one 或 horizon-two categorical transition；
  3. 对完整候选轨迹做 pairwise comparison；
  4. 只执行唯一获偏好轨迹的第一跳；
  5. 丢弃 imagined observation，读取真实证据，更新 belief，再规划。
τ* = PreferredTrajectory({Rollout_T(z_t,a)}_a) a_t* = First(τ*) o_{t+1} = Execute(M,a_t*) z_{t+1} = Update(z_t,a_t*,o_{t+1})

World model 的价值体现在 delayed effect：第一跳可能几乎没有即时收益，却能打开一个 bridge，让第二跳补全关键证据。这是它区别于 reactive retrieval 或 immediate information-gain ranking 的核心。

Learned IWM 在一次 batched graph/tensor forward 中预测全部合法 first hops。Horizon two 只能先移除 strictly dominated first hops，再为剩余 partial-order set 展开全部 second hops；不能使用 fixed-K beam pruning。

非启发式边界

5. 什么可以、什么不可以决定下一跳

允许的职责主实验中禁止的职责
Embedding similarity 提出候选相似度最高者自动获胜
Graph/factor constraint 排除 illegal 或 unsupported hopFactor posterior 或 edge priority 排序 winner
Lexical/temporal rule 作为显式 baseline在 IWM arm 中隐式用于 tie-break
IWM 预测 categorical future-belief effect模型输出 scalar reward、utility、Q-value、confidence 或 probability

tie 或 incomparable 必须触发更多证据、进一步比较或 abstain，不能默认选择列表第一项。Candidate order 必须满足 permutation invariance。

6. 控制模型输入大小

IWM/planner 不接收整个视频、raw embedding matrix、hidden answer 或未 consolidation 的全部历史。由于 L1 memory 容量固定，它可以在不做 Top-K truncation 的情况下消费完整 retained graph：question/belief tokens、current cursor node 的 key 与已读取 value、全部 retained node keys、所有 temporal/correlation edges、全部合法 cursor actions、recent history 和 budget status。

surprise-written、fixed-capacity L1 nodes + 完整 retained temporal/correlation graph + 单一 current-node cursor → 一次 batched IWM forward 预测全部合法 actions → partial-order planner

未读取 target node 只暴露 compact key/address representation，完整 evidence value 只有执行后才能读取。Qwen/Qwen3-VL-Embedding-2B 向量保存在 sidecar，作为 semantic action feature，而不是主方法 ranking gate、reward 或 supervision。

7. Belief correction 与 GTSAM backup

主方法在每次真实 observation 后更新 latent belief。GTSAM/factor graph 保留为可选 correction backend、baseline、diagnostic oracle、teacher 和 visualization 工具。

默认主方法： iwm_belief_only 可选纠错： iwm_with_gtsam_backup baseline/ablation：gtsam_always

只有真实执行、带 provenance、经过 categorical verification 的 observation 才能成为 factor；imagined rollout 永远不能写入 persistent belief。Backup 只由 identity ambiguity、contradiction、state-history conflict 或 correction failure 等显式 categorical condition 触发，不依赖手设 posterior threshold。

GTSAM 不生成 action、不遍历 graph、不排序候选、不预测 transition，也不为最终答案提供 grounding。主方法贡献必须在不使用 GTSAM 时仍然成立。

监督来源

8. Learning signal 从哪里来

CG-Bench 提供人工 clue intervals 和 terminal answers。执行一个 clue read 可以得到 advances_required_clue_coverage、partial 或 complete 等 categorical progress；完整 clue 轨迹与 leave-one-clue-out 轨迹提供 ordinal preference。

  • 未匹配的 L1.5 candidate 保持 unlabeled，不能伪造成 semantic negative；
  • Qwen-VL 生成 grounded observation descriptor，不冒充 GT relation label；
  • GPT-5.6 visual review 只是可选诊断，不能覆盖 CG-Bench ground truth；
  • Identity、state-transition、causal 和 counterevidence 需要各自可信的标注来源；
  • Validation/test 视频永不参与训练。

从同一 immutable checkpoint 执行 sibling branches，可以监督 action-conditioned observation、belief-delta prediction 和 pairwise trajectory comparison，而不必给任何轨迹赋绝对 utility。

9. Post-training 策略

  1. 用审核后的 categorical observation descriptor 与 realized belief delta 做 SFT；
  2. 用 locked sibling trajectories 做 pairwise preference optimization；
  3. 只有在标签质量成立后，才可选做 group-relative ordinal optimization。

LLM/VLM 不产生数字 reward。未来的 GRPO-style optimizer 可以从 categorical group ordering 内部计算 optimization advantage，但数据协议没有加权 heuristic reward，也没有 model-generated score。当前 GPT-OSS-120B 只用于 inference/data gathering，训练被明确暂停。

决定性实验

10. 证明 planner 因果性依赖 IWM

固定 question、evidence memory、candidate set、planner 和 read budget，只改变 world-model condition：

  1. 完整 delayed-belief IWM；
  2. no world model；
  3. shuffled IWM predictions；
  4. frozen IWM；
  5. immediate-effect-only；
  6. oracle clue ceiling，只作为诊断上界。

Answer accuracy、evidence completeness、read efficiency、action divergence、categorical transition accuracy 和 delayed two-hop success 必须分开报告，不能压成一个 lexicographic gate 或 scalar utility。

Go / No-Go

11. 支撑研究结论所需证据

Go：在 matched budget 下，完整 IWM 提升 delayed multi-hop success；移除、冻结或打乱预测会改变 action 并降低结果；prediction error 与 navigation failure 相关；收益在 candidate-order permutation 下仍存在。

No-Go：没有 IWM 仍产生相同 action sequence；收益可由 graph/embedding heuristic 解释；imagined evidence 泄漏进答案；candidate recall 太低而无法暴露所需 clue；或只有 immediate-gain case 获益。
